# Окружности: учимся работать с Git

Программа на PyQt6: по нажатию кнопки появляется жёлтая окружность случайного диаметра.

## Задание

Скопируйте проект к себе, измените его и загрузите в свой репозиторий на GitHub:

1. Окружности должны быть не только случайного размера, но и случайного цвета.
2. Интерфейс должен подключаться не из файла `UI.ui`, а из отдельного класса на Python.

## Шаг 1. Копия проекта

Нажмите **Fork** на странице репозитория учителя. Копия появится в вашем аккаунте.

## Шаг 2. Скачать на компьютер

Один раз представьтесь Git:

    git config --global user.name "Имя Фамилия"
    git config --global user.email "ваша_почта@example.com"

Затем склонируйте **свою** копию (замените ВАШ_ЛОГИН и ИМЯ_РЕПОЗИТОРИЯ):

    git clone https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
    cd ИМЯ_РЕПОЗИТОРИЯ

## Шаг 3. Запустить

    pip install -r requirements.txt
    python main.py

## Шаг 4. Случайный цвет

Измените `main.py`, проверьте запуск и сохраните изменения:

    git status
    git diff
    git add main.py
    git commit -m "Добавил случайный цвет окружностей"

## Шаг 5. Интерфейс в виде класса

Превратите `UI.ui` в код:

    pyuic6 UI.ui -o ui_form.py

В `main.py` импортируйте класс `Ui_MainWindow` из `ui_form`, добавьте его в родители своего класса
и замените `uic.loadUi(...)` на `self.setupUi(self)`.

    git add main.py ui_form.py
    git commit -m "Подключил интерфейс как класс Python"

## Шаг 6. Отправить на GitHub

    git push

При первом `push` GitHub попросит войти: через браузер или по токену (пароль от аккаунта не подойдёт).

## Что сдать

Ссылку на свой репозиторий. В истории должно быть минимум два ваших коммита.
